Personal Finance Optimizations

  • Amount First: The number is all that matters — make it the hero, not an afterthought
  • Category chips: Tap to select, no dropdown scroll. Emoji + name for instant recognition
  • Smart defaults: Today's date, last-used account, base currency — user rarely changes these
  • Type as toggle: Expense/Income/Transfer as a compact pill toggle, not full-width tabs
  • CTA shows context: "Record Expense — ¥156.30" rather than generic "Save"
  • Visual silence: Only the amount field, category, and CTA are prominent — rest is muted

What we give up

  • Transfer tab needs special treatment (from-account → to-account, no category)
  • Category chips don't scale beyond ~8 items — need "More" expander or search
  • Double-entry balance validation is hidden — errors surface only on save
  • Less suitable for power users who want to batch-enter transactions
