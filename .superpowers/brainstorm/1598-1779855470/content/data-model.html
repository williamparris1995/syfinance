第一部分：数据模型

储值消费的数据库设计 — 复用现有账户体系 + 扩展表

1. accounts 表变更

在现有 account_type 中新增 prepaid 类型：

account_type 枚举扩展

现有类型：cash | bank | credit_card | investment | loan | borrowed_out | borrowed_in | other | income | expense

+ 新增：prepaid（储值账户）

储值账户示例数据：

{
  name: "健身卡",
  account_type: "prepaid",
  ownership: "own",
  currency_code: "CNY",
  initial_balance: 0,
  icon: "💪",
  chart_code: "1003"  // 1003 预付款项（新增L2科目）
}

2. top_up_records 扩展表

类似 debt_details，1:1 关联充值交易，记录充值明细：

top_up_records 表结构
top_up_records
├── id                  TEXT PK
├── account_id          TEXT FK → accounts.id   -- 储值账户
├── transaction_id      TEXT FK → transactions.id -- 关联的转账交易
├── paid_amount         DECIMAL(20,2)           -- 实际支付金额
├── bonus_amount        DECIMAL(20,2) DEFAULT 0 -- 赠送金额
├── total_credited      DECIMAL(20,2)           -- 实际入账 = paid + bonus
├── top_up_date         DATE                    -- 充值日期
├── expiry_date         DATE NULL               -- 有效期（可选）
├── source_account_id   TEXT FK → accounts.id   -- 从哪个账户充的
├── description         TEXT                    -- 备注（如"充1000送200"）
├── created_at          DATETIME
└── updated_at          DATETIME
