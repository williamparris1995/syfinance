当前设计的问题：借入 = "自己转自己"？

从会计角度分录没错，但 UI 语义让用户困惑

当前借入流程

用户视角的困惑
用户看到的

债务账户：张三借款 (BorrowedIn)
资金账户：微信钱包 (Bank) ← 自己的账户

"我借了张三的钱，为什么要从自己的微信钱包里扣？"

实际发生的会计事件

借：微信钱包 ¥50,000 (资产+）
    贷：张三借款 ¥50,000 (负债+)

"张三把钱打进了我的微信钱包，资产增加了，同时产生了负债"

问题本质

缺少"资金来源方"的概念。

当前设计中，创建债务时只涉及 3 个账户：

账户 ownership 角色
微信钱包 own 资金到账方（资产）
张三借款 own 负债记录方（负债）
缺少→ external 资金来源方（张三本人）

如果把"张三"当作一个 external 账户，用户的选择就是："我从【张三】那里借了钱，钱打进了【微信钱包】"——语义就对了。

方案

A

资金账户 → 改成"对方账户"

借入时选对方的 external 账户（代表张三），系统自动判断：

借入：从对方账户流入你的到账账户

借出：从你的付款账户流向对方账户

前提：需要先创建 external 账户代表对方

B

保留资金账户，增加对方选择

债务账户 + 对方(external) + 你自己的到账账户

借入：选【张三(external)】→ 钱到【微信钱包(own)】

分录：借 微信钱包，贷 张三借款。对方字段用于 display

语义清晰，但需要的字段最多

C

简化：对方用文本，不要求账户

债务账户 + 对方（文本输入）+ 你自己的到账账户

跟现在几乎一样，只是把"资金账户"改名为"到账账户"

改动最小，但对方无法参与复式记账
