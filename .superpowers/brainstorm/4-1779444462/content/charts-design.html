报表页图表设计 — 方案C：环形图 + 趋势柱状图

参考 Monarch Money / Copilot 的行业最佳实践

设计原则（来自行业分析）

业界标准

  • 大数字摘要 → 瞬间回答"花了多少"
  • 环形图 → 一眼看懂分类占比
  • 堆叠柱状图 → 按月追踪趋势
  • 分类颜色来自账户设置
  • 标签直接标在图表上（无需对照图例）

避免的设计

  • 超过 8 个分类不细分（合并为"其他"）
  • 不用传统饼图（难比较相近大小的扇区）
  • 不用独立图例（强迫用户视线跳转）
  • 不堆积过多图表（一页不超过 3 个）

实现要点

📊 图表组件（recharts）
  • PieChart + innerRadius → 环形图
  • BarChart + stackId → 堆叠柱状图
  • CustomTooltip → 悬浮显示详情
  • Cell + 动态 fill → 用账户颜色
  • ResponsiveContainer → 自适应宽度
🎨 数据映射
  • 外部账户名 → 分类标签
  • 外部账户 color → 扇区/柱体颜色
  • 外部账户 icon → 图例中的 emoji
  • 图表数据来自 incomeStatementData
  • 周期过滤已在 dateRange 计算
