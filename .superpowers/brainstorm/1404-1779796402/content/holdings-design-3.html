持仓系统设计 — 实施范围 + SQL Schema

P0（数据模型 + 股票）的具体实施内容

SQL DDL（三张核心表）

-- 品种主数据（独立于账户）
CREATE TABLE securities (
    id            TEXT PRIMARY KEY NOT NULL,
    symbol        VARCHAR(50) NOT NULL,
    name          VARCHAR(100) NOT NULL,
    type          VARCHAR(20) NOT NULL,   -- stock/fund/etf/bond/gold/option/other
    exchange      VARCHAR(30),
    currency_code VARCHAR(3) NOT NULL DEFAULT 'CNY',
    deleted_at    TIMESTAMP,
    updated_at    TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (currency_code) REFERENCES currencies(code)
);

-- 持仓聚合（由交易推导，不直接编辑）
CREATE TABLE holdings (
    id            TEXT PRIMARY KEY NOT NULL,
    account_id    TEXT NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
    security_id   TEXT NOT NULL REFERENCES securities(id),
    quantity      DECIMAL(20,8) NOT NULL,
    avg_cost      DECIMAL(20,4) NOT NULL,  -- 加权平均成本
    deleted_at    TIMESTAMP,
    updated_at    TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(account_id, security_id)  -- 同一账户同一品种只有一条持仓
);

-- 交易记录（append-only，驱动持仓更新）
CREATE TABLE holding_transactions (
    id            TEXT PRIMARY KEY NOT NULL,
    account_id    TEXT NOT NULL REFERENCES accounts(id),
    security_id   TEXT NOT NULL REFERENCES securities(id),
    type          VARCHAR(10) NOT NULL,   -- BUY/SELL/DIVIDEND/SPLIT
    quantity      DECIMAL(20,8) NOT NULL,
    price         DECIMAL(20,4) NOT NULL,
    amount        DECIMAL(20,2) NOT NULL,  -- quantity * price (for BUY/SELL)
    fee           DECIMAL(20,2) DEFAULT 0,
    trade_date    DATE NOT NULL,
    transaction_id TEXT REFERENCES transactions(id), -- 关联复式分录
    notes         TEXT,
    deleted_at    TIMESTAMP,
    updated_at    TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CHECK (type IN ('BUY','SELL','DIVIDEND','SPLIT'))
);

澄清问题

A

买入时创建复式分录（推荐）

每次 BUY 自动生成：借 1101 交易性金融资产 / 贷 1002 银行存款

持仓变动和账户余额联动，保持一致性

B

买入时不创建分录，只更新持仓

更简单，但账户余额和持仓市值可能不一致

适合快速迭代，后续再加分录
