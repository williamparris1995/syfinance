设定月度预算 · 选择分类账户 + 计划金额 · 保存后自动计算 actuals
API
CreateBudget(name, month, currency_code, items[]) — items 为 BudgetItemInput { account_id, planned_amount_cents, notes } 数组(≥1)。仅 expense 账户(category) 可被选为预算分类。保存后 server read-time 调 ComputeBudgetActuals 回填 total_actual / usage_pct。
