## Backlog Items

### Sprint 1 - 本地版本发布

#### US-1: 数据加密存储
**作为** 用户  
**我希望** 我的财务数据被加密存储  
**以便** 保护我的隐私，即使设备丢失也不会泄露数据

**验收标准**:
- [ ] 首次启动时要求设置主密码
- [ ] 主密码至少 8 位字符
- [ ] SQLite 数据库文件已加密
- [ ] 密钥存储在系统密钥链
- [ ] 重启应用后需要输入密码才能访问

**Story Points**: 5  
**优先级**: P0 - Critical  
**Sprint**: Sprint 1

---

#### US-2: 简化交易记录
**作为** 用户  
**我希望** 快速记录收入和支出  
**以便** 无需理解复式记账也能使用应用

**验收标准**:
- [ ] 可以用简单表单记录收入（金额、账户、分类、描述）
- [ ] 可以用简单表单记录支出（金额、账户、分类、描述）
- [ ] 可以用简单表单记录转账（金额、源账户、目标账户、描述）
- [ ] 系统自动生成复式记账条目
- [ ] 交易列表正常显示

**Story Points**: 8  
**优先级**: P0 - Critical  
**Sprint**: Sprint 1

---

#### US-3: 还款提醒通知
**作为** 用户  
**我希望** 收到还款提醒  
**以便** 避免逾期还款

**验收标准**:
- [ ] 创建债务时可以设置提醒
- [ ] 到期前收到系统通知
- [ ] 通知包含债务名称和金额
- [ ] 可以在通知中心查看历史通知

**Story Points**: 3  
**优先级**: P1 - High  
**Sprint**: Sprint 1

---

### Sprint 2 - 同步功能启用

#### US-4: 多设备数据同步
**作为** 用户  
**我希望** 在多设备间同步数据  
**以便** 在手机和电脑上都能查看和管理财务

**验收标准**:
- [ ] 可以注册设备
- [ ] 设备间可以同步账户数据
- [ ] 设备间可以同步交易数据
- [ ] 设备间可以同步债务数据
- [ ] 同步冲突自动解决（Last Write Wins）
- [ ] 显示同步状态和最后同步时间

**Story Points**: 13  
**优先级**: P0 - Critical  
**Sprint**: Sprint 2

---

#### US-5: 安全的同步认证
**作为** 用户  
**我希望** 同步是安全的  
**以便** 只有我的设备能访问我的数据

**验收标准**:
- [ ] 设备注册需要生成唯一令牌
- [ ] 同步 API 需要令牌认证
- [ ] 令牌过期后需要重新注册
- [ ] 可以撤销设备访问权限
- [ ] 同步使用 HTTPS 加密传输

**Story Points**: 8  
**优先级**: P0 - Critical  
**Sprint**: Sprint 2
