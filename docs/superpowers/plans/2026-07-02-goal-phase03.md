## Task 2: 多账户/多债务 picker 升级(单选→多选)

**Files:**
- Modify: `yucai/client/lib/goal/presentation/pages/goal_form_page.dart`(`_linkedId` 单选 → `_linkedIds` 多选 Set)
- Test: `yucai/client/test/goal/presentation/pages/goal_form_page_test.dart`

**Interfaces:**
- Consumes:GoalView.linkedAccountIds/linkedDebtIds(多账户 list)+ CreateGoalRequested event(已接受 list)。
- Produces:GoalFormPage 多选 picker(`_linkedIds` Set<String>),submit linkedAccountIds/linkedDebtIds 多。

**背景**:Phase 1 单选(`_linkedId`),Phase 3 升级多选(`_linkedIds` Set)。account/debt picker 改多选 chips/checkbox。编辑模式预填全(不只 first)。

- [ ] **Step 1: `_linkedId` → `_linkedIds`(Set<String>)**

`goal_form_page.dart`:
- `String? _linkedId` → `final Set<String> _linkedIds = {}`(Investment/Savings 存 accountIds;DebtPayoff 存 debtIds)。
- `_canSubmit`:`_linkedId == null` → `_linkedIds.isEmpty`。
- `_applyTemplate`/type 切换:清 `_linkedIds.clear()`(非 `_linkedId = null`)。
- 编辑模式预填:`_linkedId = g.linkedAccountIds.first` → `_linkedIds.addAll(g.linkedAccountIds)`(全回填,不只 first;DebtPayoff 同 linkedDebtIds)。
- submit:`linkedAccountIds: [_linkedId]` → `linkedAccountIds: _linkedIds.toList()`(DebtPayoff linkedDebtIds)。

- [ ] **Step 2: account/debt picker 改多选**

`_filteredAccounts` picker:单选(RadioListTile/DropdownButton)→ 多选(CheckboxListTile 或 chips,多选 toggle)。tap account → `_linkedIds.add/remove(id)`。多选 UI(checkbox 或多选 chips,对齐 OD 原型 account picker chips 多选)。

```dart
// account picker 改 CheckboxListTile(或 chips):
for (final a in _filteredAccounts)
  CheckboxListTile(
    value: _linkedIds.contains(a.id),
    onChanged: (v) => setState(() => v! ? _linkedIds.add(a.id) : _linkedIds.remove(a.id)),
    title: Text(a.name),
  )
// DebtPayoff 同(debts list + _linkedIds)
```
(实现者照原型 account-picker chips 多选样式;或 CheckboxListTile 简化)
