## 3. 功能模块设计

### 3.1 端到端加密系统

#### 3.1.1 存储加密
- **算法**: AES-256-GCM
- **密钥派生**: PBKDF2 (100,000 次迭代)
- **密钥存储**: 本地密钥链 (Windows Credential Manager / macOS Keychain)
- **加密粒度**:
  - 数据库级：整个 SQLite 文件加密
  - 字段级：敏感字段（金额、账户号）单独加密

#### 3.1.2 传输加密
- **协议**: TLS 1.3
- **端到端加密**: 设备间同步数据加密
- **零知识架构**: 服务器无法解密用户数据
- **密钥交换**: X25519 密钥交换协议

#### 3.1.3 实现方案
```rust
// 加密服务接口
pub trait EncryptionService {
    fn encrypt(&self, plaintext: &[u8], key: &[u8]) -> Result<Vec<u8>>;
    fn decrypt(&self, ciphertext: &[u8], key: &[u8]) -> Result<Vec<u8>>;
    fn derive_key(&self, password: &str, salt: &[u8]) -> Result<Vec<u8>>;
    fn generate_key_pair(&self) -> Result<(PublicKey, PrivateKey)>;
}
```

### 3.2 混合备份系统

#### 3.2.1 本地备份
- **自动备份**: 可配置间隔（每小时/每天/每周）
- **增量备份**: 仅备份变化数据，减少存储空间
- **备份加密**: 使用主密钥加密备份文件
- **备份管理**: 保留最近 30 天备份，自动清理旧备份

#### 3.2.2 云备份
- **支持平台**:
  - WebDAV (NextCloud, Synology)
  - AWS S3 / MinIO
  - OneDrive / Google Drive
- **同步策略**:
  - 自动同步（后台运行）
  - 冲突解决：最后修改优先 + 用户确认
  - 版本历史：保留最近 30 天版本

#### 3.2.3 数据格式
```json
{
  "version": "1.0",
  "timestamp": "2026-05-27T10:00:00Z",
  "encrypted": true,
  "data": {
    "accounts": [...],
    "transactions": [...],
    "debts": [...],
    "holdings": [...]
  }
}
```

### 3.3 AI 助手系统

#### 3.3.1 智能分类
- **自动识别**: 基于交易描述、金额、商户自动分类
- **学习能力**: 学习用户分类习惯，持续优化
- **批量建议**: 未分类交易批量处理
- **异常检测**: 识别异常交易（金额、频率、商户）

#### 3.3.2 自然语言交互
- **查询示例**:
  - "上个月餐饮花了多少？"
  - "显示本月收入最高的 3 笔交易"
  - "我的储蓄率是多少？"
- **实现方式**:
  - 本地意图识别 + 云端 LLM 处理
  - 支持中英文查询
  - 结果可视化展示

#### 3.3.3 预测与建议
- **现金流预测**: 基于历史数据预测未来 3 个月收支
- **预算建议**: 根据消费模式推荐预算分配
- **投资分析**: 投资组合风险评估、再平衡建议
- **财务健康评分**: 综合评估财务状况（0-100 分）

#### 3.3.4 技术架构
```
用户输入 → 意图识别 → 数据查询 → LLM 处理 → 结果展示
    ↓           ↓           ↓           ↓           ↓
  本地处理   本地模型    SQLite查询  云端API    UI渲染
```

### 3.5 多币种系统

#### 3.5.1 功能设计
- **实时汇率**: 自动获取最新汇率（每小时更新）
- **多币种账户**: 支持不同币种的账户
- **自动转换**: 交易时自动转换为本位币
- **多币种报告**: 按币种分类显示

#### 3.5.2 汇率数据源
- **主要**: ExchangeRate-API、Open Exchange Rates
- **备用**: 用户手动输入
- **缓存**: 本地缓存 24 小时

#### 3.5.3 数据模型
```sql
CREATE TABLE currencies (
    code VARCHAR(3) PRIMARY KEY,
    name VARCHAR(50),
    symbol VARCHAR(5),
    exchange_rate DECIMAL(10, 6),
    last_updated TIMESTAMP
);

CREATE TABLE accounts (
    id UUID PRIMARY KEY,
    name VARCHAR(100),
    currency_code VARCHAR(3) REFERENCES currencies(code),
    balance DECIMAL(15, 2),
    ...
);
```

## 4. UI/UX 设计规范

### 4.1 主题系统
- **浅色模式**: 白色背景，专业感

- **自动模式**: 跟随系统设置
- **自定义主题**: 用户可自定义主题色

- **响应式**: 适配不同屏幕尺寸

### 4.3 交互设计
- **鼠标/触控板**: 主要交互方式
- **触摸屏支持**: 大按钮、手势操作
- **键盘快捷键**: 提高效率（可选）

### 4.4 组件库
基于 shadcn/ui 扩展：
- **Button**: 多种样式、状态
- **Card**: 信息卡片、统计卡片
- **Table**: 数据表格、排序、筛选

## 6. 技术风险与应对

### 6.1 加密性能
- **风险**: 加密/解密操作影响性能
- **应对**: 使用硬件加速、缓存密钥、异步处理

### 6.2 数据同步冲突
- **风险**: 多设备同步时数据冲突
- **应对**: 版本向量、冲突检测、用户确认机制

### 6.3 AI 准确性
- **风险**: AI 分类/预测不准确
- **应对**: 持续训练、用户反馈、人工审核

### 6.4 跨平台兼容性
- **风险**: 不同操作系统行为差异
- **应对**: 充分测试、平台特定适配
