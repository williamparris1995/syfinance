# 御财(YuCai)— Product Vision

> Product Goal — sole source. `sydusx-run` 的 product checkpoint 重读本文件判定 vision 是否仍有效。
> 由 `/sydusx-envision` 建立(回填模式,2026-08-01)。

## Positioning(定位)

御财是**面向个人专业用户的理财桌面应用**,**本地优先**架构(Go 后端 DDD+gRPC+ent / Flutter 客户端 flutter_bloc+injectable / Postgres)。

- **主力场景**:单用户个人理财(记账 / 预算 / 投资 holding / 报表 / 债务 / 目标)。
- **多用户**:当前以单用户为现实主力;多租户隔离已实现(审计 01 加固),家庭共享账本作为**预留扩展的远期愿景**,不在近期 scope。
- **差异化**:对标商业级产品(随手记 / MoneyWiz / YNAB)的功能深度,但保留本地优先与数据自主。

## Long-term Goal(长期目标 / 终态)

**终态 = 可分发的商业级个人专业理财应用。**

- **功能全面对标**:核心模块(记账 / 预算 / 投资 holding / 报表)达行业 4-5 分;gap-analysis 19 模块整体拉到行业级(报表分析 / UI 交互 / 业务逻辑正确性 / 操作效率 四维度)。
- **可分发就绪**:完整 GDPR/PIPL 合规、i18n 国际化、商业级安全审计。

## Overall Scope

### IN(终态交付)
- 19 模块功能行业级(对标随手记/MoneyWiz/YNAB)。
- 多设备同步(单用户跨设备)—— audit research 已给 Option A 方案。
- i18n + 完整 GDPR/PIPL 合规 + 商业级安全审计(后置 milestone)。
- 家庭共享账本(远期,多用户落地后)。

### 近期豁免(保私域,后置补齐)
> 基于「分阶段」决策:近期保 audit 的私域豁免以聚焦功能,以下在阶段二作为独立 milestone 补齐 —— **不是永久 OUT,是延后**。
- 完整公众级合规审计(GDPR/PIPL 数据主体权利 / 遗忘权 / 可携带 / 隐私政策 / consent)。
- i18n 国际化(client UI 从中文直写改为国际化框架,全量文案抽取)。
- 商业级独立安全审计(audit 02 密钥安全 follow-up 全补)。

## Execution Path(分阶段,关键决策)

| 阶段 | 焦点 | 合规/i18n 状态 |
|---|---|---|
| **一(近期)** | 功能对标为主 + 审计整改(R5)。聚焦 19 模块拉到行业级、审计 16 ticket 落地。 | 保私域豁免 |
| **二(后置 milestone)** | i18n + 完整 GDPR/PIPL 合规 + 商业级安全审计。独立 release,功能对标基本完成后启动。 | 撤豁免 |
| **三(远期)** | 家庭共享账本(多用户落地)。 | — |

## 标尺演进(对 audit 的影响)

御财标尺从审计时的 **「家庭多用户(私域)」** 演进为 **「个人专业理财(终态商业级)」**:

- audit 16 ticket 中基于「家庭多用户」的项(如 14 家庭共享账本)**降级为远期**。
- 基于「私域豁免」的合规项 **近期仍豁免、阶段二重做**。
- **近期审计整改(R5)仍以现有标尺为基线** —— 03 事务架构 / 04 备份 / 05 DB 约束 / 06 财务计算 / 08 错误处理 / 09 DDD-port 不受标尺演进影响,继续推进。

## 决策溯源

本 vision 经 `/sydusx-envision` light-grill 四个关键决策后收敛(2026-08-01):
1. 定位锚点 → 个人专业理财为主(非家庭多用户)。
2. 对标目标 → 全面功能对标(19 模块)。
3. 同步与共享 → 多设备同步 IN,家庭共享 defer。
4. 商业级路径 → 分阶段(先功能对标保豁免,合规/i18n 后置 milestone)。
