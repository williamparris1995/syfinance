# F74 自动落账调度与余额预检

> /sydusx-brainstorming 2026-11-02 进入(R23 sprint-1 次票,依赖 F73 配置与联动地基)。

## 概述

LoanAutoDeductScheduler 镜像 AutoRecordScheduler 范式(catch-up 补昨/防御上限/完成通知):autoDeduct 债务到期期次,绑定账户余额≥实扣额(本金+利息−优惠)→ 自动落账(F73 联动管道);不足→绝不落账+失败提醒含差额+每日自动重试;预检提醒源挂既有 due 框架(提前窗口差额文案新档位,充足则「将自动扣款」轻提示);「现在重试」手动入口;提醒频率不破 overdue 6h 重复桶。

## Stories

- [ ] S1: 调度器+落账事务(catch-up/上限/单债失败不阻断其余;完成通知)。
- [ ] S2: 预检提醒源(余额 vs 实扣差额文案档位;挂 DueScanner/DueReminderPolicy 既有框架)。
- [ ] S3: 失败重试(每日自动+「现在重试」入口)+失败提醒升级。
- [ ] S4: 全门+e2e(模拟时钟跨扣款日:够额落账/不足不落账/存钱后补扣三态)。

## 非目标(Non-goals)

罚息/宽限期建模;银行流水自动对账;多账户分摊;系统级日历通知。
