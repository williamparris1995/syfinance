# F60 周期域模型+广发收口

> /sydusx-portfolio 2026-10-14 分解。R20 sprint-1 首票。
> keywords: 账单周期,billing cycle,账单日,周期,广发,对账,财智金,专项额度

## Description

现状:F50 定案的「账期=自然月」简化(当月入账归次月 1 号账单)与银行真实周期(账单日锚定,每卡各异)不符——用户广发走查实锤(银行剩余 45,074.34 vs app 16,782.39,拆出五笔财智金疑专项额度+循环差额 2,983.48)。

本票:
1. **周期域模型**(纯 domain port):给定账单日+任意日期→归属账期区间([账单日, 次账单日));边界(账单日当天消费归属)spec grill 拍板;月末短月/31 日账单日钳制;缺账单日账户回落自然月。
2. **广发三件套**:①五笔财智金置关核验(用户银行口径确认专项额度→app 内关闭「计入卡额度占用」,照平安 35k TS 先例;输出 TS 清单)②循环差额 2,983.48 补记清单(TS)③置关+补记后重对账(目标:可用 ≈ 45,074.34,容差 ≤0.01)。
3. 周期模型单测矩阵(各账单日 1/12/20/28/31 号×月边界×闰年)。

## Stories

- [ ] S1 周期计算 port + 边界/短月/闰年矩阵(FR 域模型)
- [ ] S2 回落策略(无账单日→自然月)钉死
- [ ] S3 广发三件套 TS 清单输出 + 重对账验证
