导航方案 A · 侧栏增强

分组折叠 · 常用置顶 · 当前项强化 · 交互演示页(左侧侧栏可直接操作)

本页演示什么

方案 A
1
分组可折叠
概览 / 资产 / 收支 / 工具四个分组的组头可点击折叠与展开,组头带折叠箭头与组内项数徽标,展开收起带高度过渡动画(「工具」组默认收起,可直接点开体验)。
2
当前项高亮强化
当前页面所在导航项保留左侧 accent 指示条与高亮底色;其所在分组(概览)的组头与项数徽标同步以主题强调色点亮,一眼定位当前位置。
3
常用置顶区
侧栏顶部新增「常用」置顶区,收纳仪表盘 / 交易记录 / 报表分析三个高频入口,不参与折叠,滚动与折叠状态下始终可见。

设计取舍说明

·
为什么用组级折叠而非整栏收起
套件共 12 个导航页,单层平铺在窄高度屏幕(720p)下已经出屏;组级折叠让用户按域收起低频组(如工具),保留高频组展开,比「汉堡收起整栏」少一次往返。
·
为什么常用区不参与折叠
常用三项覆盖日常记账与看数的高频路径;无论分组如何折叠,高频路径的点击成本恒定为一次点击。

如何体验

a
点击左侧任一组头
如「资产」,观察折叠箭头旋转与组内项高度动画;「工具」组当前为收起态。
b
观察当前项
「概览 › 仪表盘」为当前页(演示态),左侧指示条 + 概览组头徽标同时点亮。
