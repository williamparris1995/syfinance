现状 · 两层叠加

  • 全局顶栏 crumb「财务 › 债务管理」为纯文本,不可点
  • 其下详情页自带一条 AppBar「债务管理 › 平安现金分期」,仅根标签可点回列表,右侧挂 编辑 / 更多 两枚方钮
  • 账户详情则是 BackButton + 标题 + 右侧 编辑 / 记一笔 / 转账 / 更多 四枚顶部钮
→

目标 · 统一

  • 面包屑统一到顶栏全路径,祖先级可点回退(套件先例:account-detail 顶栏链接态)
  • 详情页第二层 AppBar 整条退役,hero 直接上移
  • 右侧操作按钮移到右下角悬浮常驻(形态 A / B 见区块三)
