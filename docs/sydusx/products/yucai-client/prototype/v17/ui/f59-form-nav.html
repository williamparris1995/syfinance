备注
1
返回条与面包屑割裂
第二层 AppBar 的返回箭头只回上一页;顶栏面包屑「财务 › 债务管理」是纯文本不可点。返回 ≠ 回退路径,两条导航各说各话。
2
脏表单无保护
填了一半点返回箭头或侧栏导航,直接丢弃全部输入,无任何确认。
3
纵向空间被导航双占
顶栏 + 第二层 AppBar 叠两层导航,表单首屏被压掉一截。

2
AppBar 退役 · 内容上移
表单自带返回条整条删除,省出一层纵向空间,首屏直接见字段。
3
脏态守卫接管 · 无悬浮簇
已编辑时点可点级弹 FormLeaveGuard 确认;未编辑直接离开。表单页不放右下 dock:操作语义 = 保存 / 取消,收在表单底部——表单是编辑态,非浏览态。
附注:未编辑任何字段时,点面包屑直接离开,零弹窗。 已放弃修改 → 离开表单,回到「债务管理」 重置演示
