## 页面构成(F43 spec FR-1/3/8 的 UI 事实源)

- **生成进度**(FR-8):四阶段步进(读取账本→回放余额→汇编章节→计算绩效),`.gen-zone` 固定高防跳动,完成打勾→进度淡出→报告体淡入;noscript 直接展开报告体。
- **六章节单页滚动**(FR-3):①总览(hero 期初→期末净资产 + 收入/支出/结余/储蓄率/现金净变动五卡 + **附注两卡**:口径三行[回放重建/现金口径/定存列示]+未包含项[目标回顾])②资产负债(期末构成两列+期初期末变动表)③收支(支出分类横条+收入构成+日均/环比)④现金流(经营/投资/融资三类三列+**勾稽脚注**)⑤预算执行(条形+超支红态,参照 budgets.html)⑥投资绩效(五数值卡,参照 performance.html)。
- **章节锚点两变体**:`?variant=b` 切换(默认 A=顶部 sticky 横条;B=右缘竖排圆点+悬停标签);右下浮动条即时切换+replaceState 同步 URL。
