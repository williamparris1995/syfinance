# Feature — F28 占位文案清理(R12 sprint-3)

> 2026-09-15 R8 defer 承接(「占位文案清理(copy 决策)」)。

## Description

表单 hint/搜索占位/空态文案散落各页,存在格式不一(「请输入/输入/如:」混用)、术语不一、中英混杂嫌疑。本 feature 定统一文案规范(用户过目)→全量清点→按规范迁移→既有测试文案断言适配。

## Stories

- [ ] S1: 文案规范定案(规范+例外清单,用户过目)
- [ ] S2: 全量清点(grep hintText/labelText/空态文案)→清单
- [ ] S3: 按规范迁移+测试适配
- [ ] S4: 全量门
