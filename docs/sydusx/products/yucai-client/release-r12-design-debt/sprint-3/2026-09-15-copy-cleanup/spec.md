# Spec — F28 占位文案清理

> 2026-09-15 用户拍板两项口味(例如：/请输入X);R12 sprint-3;库存:hintText 39 处+空态 ~50 处(基本健康)。

## 文案规范(FR-1,定案)

| 类目 | 规范 | 例 |
|---|---|---|
| 示例前缀 | 统一「例如：」(全角冒号);四种旧式(如：/如 /例如：/例如:)全迁 | 例如：招商银行储蓄卡 |
| 必填输入 | 「请输入X」;裸名词补全(密码→请输入密码/再次输入密码→请再次输入密码) | 请输入密码 |
| 可选项 | 后缀「(可选)」(仓内半角括号惯例) | 补充说明,例如…(可选) |
| 搜索 | 「搜索X…」保留(现状已一致) | 搜索账户名… |
| 数值格式示例 | 裸值保留(0.00/2000 等格式提示) | 0.00 |
| 中文标点 | 全角逗号「，」冒号「：」;省略号「…」 | 补充说明，例如聚餐人数… |
| 空态 | 两族语义保留:「暂无X」=曾有/视图无数据;「还没有X」=从未创建;散兵(格式/标点不合)修正 | 暂无交易记录 / 还没有债务 |

## Requirements

- **FR-1 按规范迁移**:hintText 39 处逐处对表迁移;空态仅修不合规范散兵(两族保留)。
- **FR-2 门**:迁移后 grep hintText 无「如:」/「例如:」(半角)残留;必填输入无裸名词式样残留。
- **FR-3 测试适配**:文案断言(既有 test 中 grep hintText 值)按新文案适配,语义不削。
- **NFR**:全量门零回归;不改逻辑(纯字符串)。

## Scope boundary

| 排除 | 理由 |
|---|---|
| labelText/errorText 校验文案 | 校验语另有体例,非本票(超范围即 scope creep) |
| demo 种子/测试夹具文案 | 非生产面 |
| i18n | 阶段二 |
