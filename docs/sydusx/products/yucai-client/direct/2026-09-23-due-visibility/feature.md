# Feature — 到期事项常显提醒:首页提醒条 + 托盘行 + 收件箱(直落)

> 2026-09-23。既有:v1.0.10「到期催办提醒」主动瞬态层(系统通知 6h 催办+挂失)已上线;
> 用户问「重要到期事项能否常显避免忘记 + 行业最佳实践」,brainstorm 收敛三层模型,
> grill 六决策拍板见 spec.md Grill record。直落 feature(无 release,`direct/` 归置首立)。

## Description

补齐三层提醒模型缺的两层 + 通知中心:①**被动常显层**——账户页净资产 hero 上方聚合条
「⏰ N 笔待还 · 最近 X 天后」(窗口 = advanceDays + 逾期,挂失过滤),点击展开明细
(F37 着色桶),条目直达处理动作(信用卡→还款对话框 / 期次→债务详情页,候选携带
强类型路由目标);②**环境可见层**——托盘数据头区待还行(永不含金额、不跟隐私开关、
无候选不显示,复用 F25 三触发刷新);③**应用内通知中心(收件箱)**——两区(待处理
置顶/历史沉底)+ 三态(待处理/已处理/已挂失,领域真相驱动自动流转)+ 新增小圆点
(仅待处理区,lastSeen 时间戳)+ 历史永久保留 + 类型字段预留;入口 = 聚合条「查看全部」
+ 托盘菜单项(无候选时托盘唯二)。

边界:不新增提醒来源(候选 = DueScanner 双源同一份);既有系统通知行为逐字不变;
无侧栏/标题栏入口;不做已读未读全模型。
