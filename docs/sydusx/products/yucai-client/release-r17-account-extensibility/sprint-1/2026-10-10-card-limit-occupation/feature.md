# Feature — F50 卡贷额度占用重落(R17 sprint-1)

> 2026-10-10 立项。release 级拍板见 [release.md](../../../release-r17-account-extensibility/release.md) Decisions;本票=重落 `794bc677`(银行口径占用)并治三重缺口(债级开关/期表偏移/口径钉死)。

## Description

现状:信用卡「已用/可用额度」完全不含挂接卡贷的未出账占用(794bc677 被 8088dd36 回退后零残留),与银行 App 显示差距大(平安:御财可用 ~¥49.7k vs 银行 ¥38,728.30)。目标(grill + 真库/银行真值对账后定稿,详见 [spec.md](spec.md)):①占用公式 = 卡已出账欠款 + Σ「开关开」挂接卡贷的**剩余本金(期表口径,禁用载体户余额)**;②每笔卡贷**债级「计入卡额度占用」开关**(默认开;¥35k 平安备用金银行走专项额度不占卡线,置关);③显示面=账户页卡片+详情页四卡,**display-only** 不动余额/净资产;④平安四笔分期期表对账修复(各晚一期,补记最早期还款);⑤银行真值校准回归测试(平安可用 == ¥38,728.30 分毫不差)。零 proto/server 改动;载体户息费缺口(¥3,189)另开票。

## Stories

- [ ] S1: domain 占用纯函数(剩余本金 + 开关过滤)+ 四组 fixtures 单测(平安真值/e招贷零占用/开关关/广发)
- [ ] S2: 债级「计入卡额度占用」开关 — 本地持久化 + 债详情/表单 UI,默认开
- [ ] S3: 显示面接线 — 账户页信用卡片(已用/额度+利用率条)与详情页四卡(已用/可用),display-only 断言
- [ ] S4: 期表对账修复 — 平安四笔各补记一期最早期还款,修复后剩余与银行真值一致(±¥0.02);真库验证闭环
- [ ] S5: 银行真值校准回归测试 — 平安可用 ¥38,728.30 基准用例进测试套件
