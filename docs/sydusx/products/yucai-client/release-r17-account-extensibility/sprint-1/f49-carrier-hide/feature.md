# F49 — isSystem 激活·载体户隐藏

> R17 sprint-1 第一票。来源:R17 立项(2026-10-09)三轮设计对谈 + 行业调研 + 账户字段审计(项目记忆 `account-fields-audit`)。需求全文见 [spec.md](spec.md)。

## Description(做什么)

卡贷**并入模式**(挂接卡账单,平安/广发型)自动创建的贷款负债户是账务载体而非用户真实账户——银行 app 无此账户,现却以平级贷款行露出,打破银行镜像。本票激活账户表既有 `isSystem` 列:并入型载体户建户置 true,账户页列表与全部账户选择器过滤之;贷款组以「信用卡分期 N 笔 ¥X」汇总行保留可见性并跳转债务规划;净资产与账务零改动。**独立账单模式(e招贷型)的账户是真实账户,永不隐藏**(判别:债挂接非空 / 账户带账单日)。

## Why(为什么)

行业惯例(Beancount `CC:Installment` 子账户、GnuCash 分期专用子账户)载体一律从属呈现;消费级产品(钱迹等)根本不给用户看载体。transaction 分类模块已实现 isSystem(系统内置分类行),账户侧激活有库内先例。绑定模式边界(镜像抹除回可见)经 grill 拍板为已知边界,proto 透传归未来卡贷 bound 支持票。
