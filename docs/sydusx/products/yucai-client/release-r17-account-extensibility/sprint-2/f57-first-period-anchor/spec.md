# F57 spec — 期表首期锚点选项(放款当期/放款次月)

> /sydusx-analysis 2026-10-12 定稿。**根因修正版**——原立票(2026-10-10)「起始日==账单日顺延假设,分歧窗口仅此一天」经真库取证**作废**:平安卡账单日=1 号,四笔放款日 24/25/12/2 号,该代码分支从未触发。
> 取证链(快照 2026-10-08 pre-fix + 用户银行 App 核验):四笔银行真值剩余均恰比库内少一期月供;5k(8/2 放款)排除「账单日锚定」备择(若锚 1 号差应为 0);用户核验 **5k 首期账单=8 月 2 日=放款日当天** → 平安=当期起扣(首期锚在放款日)。用户口径:账期=自然月,当月入账归次月 1 号账单——首期属哪个月即落哪期账单,与放款日几号无关。

## Goal

新建卡贷(并入模式)时,首期锚点可选:**放款当期**(首期=放款日当天,平安口径)/ **放款次月**(首期=放款日+1 月,现状,典型银行)。分歧是银行起扣惯例的真实差异(两种都存在,用户库内即有),每笔创建都要回答,故选项**常驻**(v15 形态 B 经数据反转当选)。

## Requirements

### Requirement: FR-1 首期锚点选项(常驻,并入模式)
- [ ] FR-1
债务表单卡贷区(并入模式)**SHALL** 常驻「首期锚点」单选:「放款次月(默认)」/「放款当期(平安)」,副行以所选起始日实例化日期(如 8/2 起始 → 次月 9/2 / 当期 8/2);独立账单模式**不显示**本选项(e招贷独立账单无此分歧,既有行为不变);期次预览(若有)SHALL 随选项刷新。
#### Scenario: 默认次月
GIVEN 并入模式,起始日 2026-08-02
THEN 默认选中「放款次月」,预览/生成首期 = 2026-09-02
#### Scenario: 选当期
WHEN 选「放款当期」
THEN 首期 = 2026-08-02(放款日当天),此后逐月同日
#### Scenario: 独立模式不显示
GIVEN 独立账单模式
THEN 无该选项,生成行为与现状逐位一致

### Requirement: FR-2 生成器分叉
- [ ] FR-2
`_cardLoanScheduleDates` SHALL 支持首期锚点参数:次月=现状(nextAfter 语义);当期=首期即起始日,此后逐月同日(月末钳制照引擎既有 pinned 契约)。参数为**生成期参数**(经 CreateDebtParams 可选字段,缺省次月),物化进期表日期,**不持久化为债字段**(零 drift 列/零 proto;编辑不重排既有守卫不变)。
#### Scenario: 当期生成
GIVEN 起始 2026-08-02,18 期,当期锚点
THEN 期表首期 2026-08-02,第 18 期 = 2027-01-02
#### Scenario: 存量零影响
GIVEN 既有任意卡贷债
THEN 本票落地后其期表逐位不变(回归钉死)

### Requirement: NFR-1 门
- [ ] NFR-1
全量 flutter test 绿 + analyze 基线 + e2e;既有四笔(已 TS4 补记修复)期表零变化。

## Scope boundary

| 排除 | 理由 |
|---|---|
| 独立账单模式选项 | e招贷独立账单口径无此分歧(F50 取证:解挂债不涉) |
| 债字段持久化/跨设备同步 | 生成期参数物化进日期即全部语义;编辑不重排既有守卫 |
| 按卡记忆默认/preset 携带 | F52 预设组合点留 backlog(信用卡预设与卡贷锚点是两层) |
| 存量迁移 | 四笔已 TS4 补记修复;新建才用选项 |

## Grill record

- **根因对质(2026-10-12)**:用户以自然月账期模型质疑原立票 → 真库取证推翻「仅一天窗口」(分支从未触发);用户核验 5k 首期账单=放款日当天,定案「首期起点=真实分歧,常驻选项」。原 v15 形态 A(条件 callout)基于错误前提作废,形态 B 当选——**由数据反转,非偏好**。
- **默认值**:次月(兼容既有与其他银行;平安型创建时手动选当期)——推荐采纳,未另质询。
