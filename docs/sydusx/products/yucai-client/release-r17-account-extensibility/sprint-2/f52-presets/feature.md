# F52 — 花呗/白条等建户预设模板层

> R17 sprint-2 第一票。来源:R17 立项「花呗/白条以 creditCard 类别+预设接入,零 schema」+ 行业调研(小星记账/钱迹预设先例)+ 账户字段审计(记忆 account-fields-audit)。分析阶段进行中——spec 待 grill 后定稿。

## Description(做什么)

建户流程提供常见信用产品预设模板:选信用卡类别时经预设一键预填(产品名/类别/额度/账单日/还款日等),让花呗/白条等免手填参数。零 schema 改动(全部走既有 creditCard 字段);预设清单与呈现形态 spec 拍板;per-product 扩展属性不加 STI 列(metadata JSON 方向仅评估)。

## Why(为什么)

用户拍板「花呗、白条肯定要接入,app 内部自带这些常见分类」;行业惯例(小星记账把花呗/白条/月付建为信用账户预设;钱迹资产管理同类)。信用账单语义(消费记支出/月度全额还)与 creditCard 类别完全同构,预设层是呈现与效率问题而非结构问题。

## Stories

待 spec 定稿后细化(预设清单/呈现形态/预填字段/与 F57 锚点组合点均 grill 拍板)。
