# Spec — F21 清空数据重新开始（备份先行）

> 2026-09-14 用户需求：清空重置功能，执行前确认+自动生成备份，可找回。

## Requirements

- **FR-1 入口**：设置页「数据」区新增「清空数据重新开始」行（negative 色调警示样式）。
- **FR-2 三步确认**：点击 → ①警示 dialog（当前数据规模 账户 N/交易 N+三重警示）「我已了解风险」→ ②密码+备份位置 dialog（设定存档密码；默认文件名 yucai-reset-backup-<yyyyMMdd-HHmm>.ycb；FilePicker.saveFile）→ ③最终确认（备份路径摘要+「确认清空」红色按钮）。
- **FR-3 备份先行 fail-closed**：步骤②保存失败或取消 → 整体中止（不清空）。备份复用 exportAll+ArchiveCodec.encrypt 既有链。
- **FR-4 清空与重启**：最终确认后：close DB → 删 yucai.db（含 -wal/-shm）→ 提示「已清空并备份到 <路径>；可用 导入存档+该密码 找回；应用即将退出」→ exit(0)（进程重启最干净，DI 热重置复杂易漏，注释论证）。
- **FR-5 找回**：既有导入存档能力零新开发；成功/退出提示文案明示路径。
- **FR-6 范围**：仅 guest 本地模式显示（绑定态隐藏——server 数据另议，注释）；测试=widget 确认流/中止路径+集成（测试库路径清空）；全量门。
