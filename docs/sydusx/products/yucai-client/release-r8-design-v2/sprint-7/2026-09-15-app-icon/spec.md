# Spec — F23 字符标「御」品牌图标全套

> 2026-09-15 brainstorm(方向:字符标)+ 视觉变体三选一(用户拍板:**A 实心墨底+金渐变「御」**)。现状缺口:runner 图标为 Flutter 模板默认;design-v2 品牌视觉未落地系统层。

## Requirements

- **FR-1 视觉规格(变体 A)**:墨底 `#0B0E13` 圆角方块(圆角率 ~19%)+ 鎏金渐变「御」单字(`#E8C07A→#C9964A` 对角),微软雅黑 Bold 栅格化,字面占比 ~64%(≥32px 档);**≤24px 简化形 = 印章式手绘基元**(暗金圆角外框 + 亮金三笔抽象「御」:左竖=彳/右上横=卸/右下横=止,双色阶纯色弃渐变)——视觉 QC 两轮裁决:字体降采样与滤波剪影在 16px 均不可辨,手绘印章形达到可发布标准(行业先例:支付宝 16px「支」两笔);与 app 内部视觉(墨鎏金主题)同源。
- **FR-2 exe 图标替换**:合成多尺寸 ICO(16/24/32/48/64/256,Microsoft 官方最低档全含)替换 `windows/runner/resources/app_icon.ico`——**不用 flutter_launcher_icons**(Windows 端单尺寸缺陷,#573)。
- **FR-3 托盘图标替换**:`assets/tray_icon.ico` 替换为 **16/24 简化形**专用档(印章三笔形;托盘渲染 16@100%/24@150% DPI)。
- **FR-4 管线可重跑**:生成脚本入库(`yucai/client/tool/gen_app_icon.py`,PIL),源参数(色值/占比/圆角率)集中常量;文档注明字体依赖(Windows 内置 `msyhbd.ttc`)。
- **FR-5 Runner.rc 核对**:只核对图标资源引用/版本元数据现状,异常上报不擅改。
- **NFR-1 16px 可读性**:16px 档「御」可辨(设计基线;人工验收确认)。
- **NFR-2 零回归**:资产替换后全量 `flutter test` + `flutter analyze` 与基线一致(ICO 结构测试守护尺寸档齐全)。

### Scenario(FR-2/NFR-2)
- GIVEN 替换后的 app_icon.ico WHEN 解析 ICO 目录 THEN 含 16/24/32/48/64/256 六档。
- GIVEN 替换后 WHEN 全量测试 THEN 基线全绿(资产不碰代码路径)。

## Scope boundary(排除项 + 辩护)

| 排除 | 理由 |
|---|---|
| macOS/Linux 图标 | 产品现役仅 Windows(R7 windows-usable);跨平台时另起 |
| 手绘 SVG 字形路径 | 可控性高但成本不成比例;字体栅格化可重跑且雅黑 Bold 笔形合格(变体预览已验证) |
| flutter_launcher_icons | Windows 端只生成单尺寸 ICO(#573),质量不达标 |
| exe 版本号/产品名变更 | Runner.rc 只核对;变更属发布流程(F24 线) |
| F24 检查更新/关于入口 | defer 立项候选在案 |

## Grill record

| 决策 | 挑战 | 定案 |
|---|---|---|
| 设计方向 | 字符标 vs 几何 vs 具象 | 字符标「御」(brainstorm 三选一) |
| 变体 | A/B/C 三款实渲对比(QC:B 小档描边挤字面) | A 实心金渐变字(用户拍板) |

| ICO 档位 | 最低 5 档 vs 加 64 | 16/24/32/48/64/256 六档(64 补高分档) |
