# Feature — F25 托盘数据头 + 快捷操作(R8 sprint-7)

> 2026-09-15 grill 中用户提出(D3 连带拆分,四项:「版本号/检查更新」归 F24,「托盘信息展示/快捷操作」归本 feature)。

## Description

托盘右键菜单从纯「窗口管理」升级为「数据速览 + 快捷入口」:

1. **数据头区**:菜单顶部动态禁用项,展示「今日收支 / 本月结余(或净资产)」等核心数字——本地 drift 聚合查询(复用 dashboard 侧既有聚合口径,不新造口径);刷新时机挂在 F22 重构后的扫描 tick / 窗口事件上。
2. **快捷操作**:「记一笔」= 显示窗口并直接跳转记账表单。
3. **金额隐私开关**:设置页新增「托盘显示金额」开关(金额在托盘是肩窥隐私面;关闭时数据头显示「金额已隐藏」)。默认值实施时用户定。

前置依赖:F22 的 TrayController 可注入化 + 菜单重构(本 feature 骑在其地基上,排 F22 之后实施)。

## Stories

- [ ] S1: 数据查询 port(今日收支/本月结余聚合,复用 dashboard 既有口径,注入 TrayController)
- [ ] S2: 托盘菜单动态数据头区(禁用项;扫描 tick / 窗口事件刷新)
- [ ] S3: 「记一笔」快捷操作(显示窗口 + 跳转记账表单路由)
- [ ] S4: 设置页「托盘显示金额」开关(关闭时数据头显示「金额已隐藏」)
- [ ] S5: 测试(聚合口径一致性/刷新触发/隐私开关/快捷操作路由)
