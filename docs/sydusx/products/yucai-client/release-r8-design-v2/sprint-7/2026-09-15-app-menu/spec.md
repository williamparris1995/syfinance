# Spec — F22 退出入口与关闭行为 + 扫描调度治本

> 2026-09-15 brainstorm→grill 定案(四决策见 Grill record;需求集经用户确认)。目录名 app-menu 为立项时方案 A 遗留,最终方案已收敛为「设置页退出按钮 + 扫描治本」。

## Requirements

- **FR-1 退出入口**:设置页最底部「退出御财」按钮(negative 色调警示样式),点击即时退出——与托盘退出同路径(TrayController.stop:取消定时器/销毁托盘 → exit(0)),无确认弹窗。
  - GIVEN 设置页 WHEN 点「退出御财」 THEN 托盘图标销毁、进程 exit(0)、无确认步骤。
- **FR-2 关闭行为设置**:设置页「关闭按钮行为」= 隐藏到托盘(默认,保持现状)/ 退出程序;持久化(照 ThemeSettings 先例)。
  - GIVEN 行为=退出程序 WHEN 点窗口 X THEN 走与 FR-1 相同退出路径,不隐藏。
- **FR-3 首次关闭一次性对话框**:行为=隐藏 且 trayReady 且未标记 → 点 X 弹「御财将最小化到系统托盘继续运行」,`[最小化到托盘]`(默认) + `[退出程序]`;**Esc/× = 取消本次关闭、窗口保留、不消耗标记**(未完成的选择不算被告知过);任一按钮选择后标记持久化,此后点 X 直接隐藏。
  - GIVEN 首次点 X(隐藏行为) WHEN 选「最小化到托盘」 THEN 窗口隐藏且下次点 X 不再弹。
  - GIVEN 对话框打开 WHEN 按 Esc THEN 窗口保留,下次点 X 仍弹。
  - GIVEN 已标记 WHEN 点 X THEN 直接隐藏,不弹。
- **FR-4 变更即扫**:债务期次写入(新增/编辑/删除/标记已付)与自动记账规则写入成功后,防抖 500ms 触发一轮扫描(autoRecord+due 同 _scanAndMark 语义;幂等由 ReminderLogStore 既有保证)。
  - GIVEN 今日新记一笔今天到期的债务期次 WHEN 写入成功 THEN 秒级内收到当日档提醒,而非等次日/重启。
- **FR-5 可配扫描间隔**:设置页「提醒检查频率」= 15/30/60 分钟(默认 30=现状);周期 tick **无条件重扫**(撤 30 分钟跨日门槛——该门槛是工作量优化非通知策略,scanner 按条目按档当日幂等,重扫安全);启动 +10s 延迟首扫保留;间隔变更即时重臂定时器。
  - GIVEN 间隔=15 分钟 WHEN tick 触发 THEN 无条件扫描,当日已发条目不重复通知。
- **FR-6 托盘菜单瘦身**:撤「立即检查」项 → 托盘菜单 = 显示御财 / 退出(手动逃生口由 FR-4/FR-5 治本取代)。
- **NFR-1 托盘失败 fail-safe 不变**:行为=隐藏 但 trayReady=false → 仍真退出(防僵尸窗口语义,历史 user-acceptance 修复);该态首对话框不弹。
- **NFR-2 幂等重入**:任意触发路径(启动首扫/周期 tick/变更防抖)重入不产生重复通知——ReminderLogStore 既有保证,补回归测试。
- **NFR-3 现有零回归**:TrayController 注入化重构后,托盘常驻/到期提醒/自动记账/单实例守卫行为不变;全量 flutter test + analyze 门绿。

## Scope boundary(排除项 + 辩护理由)

| 排除 | 理由(grill 中被挑战后的辩护) |
|---|---|
| 顶栏应用菜单按钮(⋯) | 用户裁定:仅剩设置/退出两项时菜单仪式感大于内容;退出落设置页;F24「检查更新/关于」到来时再议落点 |
| 自定义窗口标题栏 | shell 打磨后续线,与本期缺口无关(defer 在案) |
| 托盘数据头/记一笔 | F25 独立 feature(骑本 feature 注入化地基,排后实施) |
| 自动更新(版本号/检查更新) | F24 defer 立项候选:跨客户端/CI/发布/安全三面,独立排期不夹生 |
| 首提示 OS 通知形态 | 关闭路径上前置对话框可发现性更好且顺带提供一次性选择(用户拍板) |
| i18n | 项目阶段二统一 |
| 托盘/应用菜单条目单一事实源 | 两菜单条目均 ≤2 项,无漂移风险;条目增多再抽 |

## Grill record

| 决策 | 挑战 | 定案 |
|---|---|---|
| D1 退出即时性 | 进行中表单会蒸发;「与托盘一致」或同为缺陷而非先例 | 即时退出无确认(用户裁定接受代价) |
| D2 首关提示形态 | 关闭路径打断(Zoom 式嫌恶) vs OS 通知易漏 | 隐藏前一次性对话框,双按钮;Esc=取消关闭不消耗标记 |
| D3 手动检查去留 | 应用内静默动作无回声;更深层=同日新建到期项不被扫(跨日门槛副作用) | 治本:变更即扫 + 可配间隔周期扫;双菜单撤「立即检查」 |
| D4 应用菜单形态 | 两项菜单仪式感 vs 单退出钮突兀且 F24 无落点 | 不加菜单;设置页底部退出按钮 |
| 扫描门槛成因 | 事实核查:跨日门槛是省工作量优化,scanner 本身按条目幂等 | 撤门槛改无条件周期重扫(安全) |

## Feasibility

- **技术 ✅**:纯客户端;window_manager/tray_manager 在位;设置持久化照 ThemeSettings 先例;变更触发需在债务/自动记账写入路径注入扫描 port(跨模块走 port 模式,符合仓约束);无新依赖包。
- **经济 ✅**:中小体量,无基础设施成本。
- **运营 ✅**:风险=间隔变更重臂定时器/撤菜单项是行为变更(发布说明注明)/防抖参数调优;均可控。
