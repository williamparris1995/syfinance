# Feature — F22 退出入口与关闭行为 + 扫描调度治本(R8 sprint-7)

> 2026-09-15 brainstorm→grill;四决策与需求集确认见 [spec.md](spec.md) Grill record。目录名 app-menu 为立项时方案 A 遗留,终案已收敛(无应用菜单)。

## Description

缺口:退出进程无应用内入口(唯一路径 X→托盘→右键退出三步;侧栏「登出」是账号登出≠退出);关闭行为强制隐藏无设置无提示;到期扫描的跨日门槛导致「同日新建的到期项当天不提醒」,靠手动「立即检查」逃生口补——而它只在托盘菜单,托盘折叠/失败时彻底不可达。

方案:①设置页底部「退出御财」按钮(即时退出,与托盘退出同路径);②「关闭按钮行为」设置(隐藏到托盘[默认]/退出程序,持久化)+ 首次隐藏一次性对话框(最小化/退出二选一,Esc=取消不消耗标记);③扫描治本:债务期次与自动记账规则写入→防抖 500ms 即扫,30 分钟跨日门槛→用户可配间隔(15/30/60,默认 30)无条件重扫,托盘菜单撤「立即检查」;④TrayController 提为可注入(getIt),为 F25 托盘数据头打地基。

依据:Microsoft Win32 通知区指南(close-to-tray 用户可选+应用内显式退出)、提醒类应用事件驱动最佳实践(变更即扫/周期兜底/按条目去重三件套,后两者已在仓,补第一件)。

## Stories

- [ ] S1: TrayController 可注入化(getIt 注册;scan/stop/exit 路径统一;现有容错与 fail-safe 语义不变)
- [ ] S2: 设置页底部「退出御财」按钮 + 「关闭按钮行为」设置项(持久化,照 ThemeSettings 先例)
- [ ] S3: 首次关闭一次性对话框(默认最小化/退出程序;Esc=取消关闭不消耗标记;标记持久化)
- [ ] S4: 变更即扫(债务期次[新增/编辑/删除/标记已付]与自动记账规则写入成功→防抖 500ms 触发扫描)
- [ ] S5: 可配扫描间隔(「提醒检查频率」15/30/60 分钟默认 30;撤跨日门槛改无条件重扫;变更即时重臂)
- [ ] S6: 托盘菜单撤「立即检查」(余 显示御财/退出)
- [ ] S7: 测试与全量门(FR-1~6 + NFR-1~3 场景化测试;flutter test 全量 + analyze 零新增)
