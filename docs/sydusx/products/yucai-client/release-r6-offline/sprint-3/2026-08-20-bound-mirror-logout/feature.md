# Feature — 绑定后镜像写穿透 + 登出回本地

> R6 sprint-3 feature H(依赖 G 的绑定状态机;M2 决策落地)。

## Description

**镜像写穿透**:绑定态下在线写成功后同步写本地 drift(写穿透,不做离线队列——离线续写是 ticket 16),使本地库持续等于服务端数据,为「登出回本地」与未来离线读缓存铺底。**登出回本地(M2)**:登出 → 回游客态,数据源切回本地 drift,使用最后镜像(绑定期间数据已在本地);不做「登出前从 server 拉全量回本地」(defer,记录为已知边界:镜像滞后于登出时刻的场景在 design 评估)。

## Stories

1. 写穿透 seam:绑定态在线写成功 → 同步写 drift(各模块按 sprint-1 范式复制)
2. 镜像一致性:绑定态使用期间本地=服务端(抽样比对测试)
3. 登出流程:清 token(现状)→ 回游客态 → 数据源切本地,业务页面无缝可用
4. 登出边界记录:镜像滞后场景(如多端写入)的 accepted-risk 文档化(design.md)
5. 测试:绑定→写→登出→本地可见 / 绑定→登出→再登录(幂等,不重复上传)
